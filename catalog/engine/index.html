Каталог двигателя Cummins QSK60 CM2150 MCRS

Подробный заводской каталог двигателя Cummins QSK60 (ESN 33239746, CPL 3451), установленного на самосвал NTE240. Собран из официального каталога parts.cummins.com по серийному номеру.

Слева — системы двигателя, внутри каждой перечислены узлы (варианты исполнения). Откройте узел: рядом с чертежом появится список позиций. Номер на чертеже совпадает с номером позиции в таблице. Щелчок по номеру детали открывает карточку с фотографиями, массой и габаритами.

Цены (CNY) подставлены из прайс-листа NTE240 там, где номер детали совпал. Через поиск вверху можно найти деталь по номеру или наименованию.
