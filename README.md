# NHL NTE240 — интерактивный каталог запасных частей

Интерактивный веб-каталог запчастей для самосвала **NHL NTE240 Mining Truck**,
построенный из заводского каталога (PDF) и прайс-листа (XLSX).

## Структура репозитория

```
catalog/            ← ГОТОВЫЙ каталог. Самодостаточный: можно выгрузить ТОЛЬКО эту
                      папку и открыть index.html — всё работает офлайн.
tools/              скрипты извлечения (пересборка каталога из источников)
sources/
  active/           источники, из которых собран текущий каталог
  archive/          неиспользуемые / более старые издания книг (в каталог не входят)
skill/parts-catalog/  переносимый «скилл» — как собрать такой каталог для других книг
```

**Чтобы отдать заказчику / выгрузить из песочницы — берите только папку `catalog/`.**

## Открыть каталог

Откройте `catalog/index.html` двойным щелчком — сервер и сборка не нужны.
Всё работает из `file://`: данные подключаются как JS-глобалы, чертежи — по
относительным путям.

Возможности:

- **Двигатель Cummins QSK60 в двух видах:**
  - **Глава 700 «Двигатель Cummins QSK60 (из PDF)»** — каталог двигателя,
    извлечённый из заводского PDF `QSK60.zip` (как в дереве разделов, вместе с
    остальными главами NTE240). В шапке каждого раздела главы 700 — ссылка на
    подробный каталог Cummins.
  - **Подробный каталог двигателя Cummins QSK60** (кнопка «🛠 Каталог двигателя
    QSK60 (Cummins)» в шапке) — отдельное самодостаточное приложение
    `catalog/engine/`, собранное из официального каталога parts.cummins.com по
    серийному номеру двигателя (ESN 33239746, CPL 3451): 92 системы, 1041 деталь,
    чертежи узлов, фотографии и характеристики (масса, габариты) деталей, цепочки
    замен номеров. Цены (CNY) подставлены из прайса NTE240 по совпадению номера
    детали (≈277 из 1041 уникальных номеров). У 8 узлов, для которых Cummins на
    сайте чертёж не публикует (блок цилиндров, турбокомпрессор, ответственные
    детали, крышка передних шестерён, картер маховика, маховик, выпускной
    коллектор, крышка клапанов), чертёж **дополнен из PDF-каталога** и помечен
    соответствующей подписью;
- дерево разделов (главы → разделы) и полнотекстовый поиск по номеру детали и
  наименованию (中文 / English / русское из прайса);
- каждый чертёж показан вместе со своим списком позиций (карусель, если
  чертежей несколько), клик по чертежу — увеличение;
- таблица позиций: № · номер детали · наименование · цена (CNY) · кол-во по
  схеме · требуемое количество · «＋» в заказ;
- корзина-спецификация (сохраняется в браузере): серийный номер машины,
  редактируемые количества, цена × кол-во и итог, экспорт заказа в Excel (.xlsx) и на печать;
- экспорт всех уникальных номеров каталога в Excel (.xlsx) со всей аналитикой
  (RU-наименование, цена, группа, взаимозаменяемый артикул, разделы);
- **обновление цен локально из браузера** (кнопка «💲 Обновить цены») —
  загрузка нового прайса `.xlsx` или `.csv` прямо в каталоге, без пересборки:
  цены применяются сразу и сохраняются в браузере, а кнопкой «Скачать
  prices.js» их можно зафиксировать в файле каталога навсегда (см. ниже);
- **Руководство по эксплуатации и обслуживанию** (кнопка в шапке) — руководство
  оператора NTE240 в виде листаемого документа с оглавлением, картинками и
  поиском по тексту;
- **перекрёстные ссылки** каталог ⇄ руководство: из раздела каталога — переход к
  теме в руководстве (с автопоиском и ссылкой «вернуться в раздел»), из
  заголовков руководства — переход к соответствующей главе каталога;
- **Инструкции по ремонту и обслуживанию по разделам** (кнопка «🔧 Ремонт и
  обслуживание» и ссылка в каждом разделе): сервисная книга разложена **по
  разделам каталога** — в разделе, где есть инструкция, появляется кнопка
  «🔧 Инструкция по ремонту раздела →», а страница ремонта ссылается обратно на
  раздел каталога.

## Срок действия и пароль

Каталог действует **1 месяц (31 день) с даты издания**. До окончания срока он
открывается свободно. После окончания срока при открытии `index.html` (а также
руководства и страниц ремонта) появляется полноэкранное окно с запросом пароля —
без пароля каталог не открывается. Правильный пароль запоминается в браузере,
повторно вводить его не нужно.

Задать пароль и дату издания:

```bash
python3 tools/set_catalog_password.py "<пароль>" [ГГГГ-ММ-ДД] [дней]
# пример: python3 tools/set_catalog_password.py "мой-пароль" 2026-07-31 31
```

- `<пароль>` — обязателен; в `catalog/gate.js` пишется только его SHA-256, сам
  пароль в файлы не попадает;
- `ГГГГ-ММ-ДД` — дата издания (по умолчанию сегодня);
- `дней` — срок действия (по умолчанию остаётся 31).

Под-каталог двигателя QSK60 (`catalog/engine/`) закрыт тем же паролем и сроком
(`catalog/engine/gate.js`); скрипт `set_catalog_password.py` обновляет **оба**
файла сразу. На Vercel (один домен) пароль вводится один раз — открываются и
основной каталог, и каталог двигателя.

> **Важно:** это клиентская защита статического сайта — напоминание о
> сроке/лицензии, а не криптостойкая защита. Технически подготовленный
> пользователь может её обойти. Текущий пароль — временный `razvitie2026`,
> замените его своим командой выше перед выдачей каталога.

## Обновление цен локально (без пересборки)

Цены можно обновить **прямо в каталоге**, не запуская Python и не заходя в
песочницу. В шапке — кнопка **«💲 Обновить цены»**:

1. Нажмите её и выберите файл прайса — **`.xlsx`** (ваш обычный формат) или
   **`.csv`**. Нужны столбцы «Артикул», «Взаимозаменяемый артикул»,
   «Наименование», «Цена CNY без НДС», «Группа» (как в текущем прайсе; строка
   заголовка может быть не первой).
2. Цены **применяются сразу** ко всему каталогу и корзине и **сохраняются в этом
   браузере** (при следующем открытии останутся). Кнопка «Сбросить к заводским»
   возвращает цены из файла `prices.js`.
3. Чтобы обновление стало **постоянным и переносимым** (ушло вместе с папкой
   `catalog/` другим пользователям) — нажмите **«Скачать prices.js»** и положите
   скачанный файл в `catalog/data/` вместо старого `prices.js`.

> `.xlsx` читается прямо в браузере (Chromium/Edge, офлайн). Если формат почему-то
> не открывается — сохраните прайс как `.csv` и загрузите его. Ведущие нули в
> артикулах (`00106267`) сохраняются.

Массовая пересборка из исходного прайса по-прежнему делается скриптом
`tools/extract_prices.py` (см. ниже) — локальная загрузка удобна для быстрых
правок цен на месте.

## Пересборка из исходников

Скрипты сами находят источники в `sources/active/`.

```bash
pip install pymupdf olefile openpyxl playwright

python3 tools/extract_pdf_catalog.py        # главы 020–210 -> parts.js + drawings/
python3 tools/extract_inverter_catalog.py   # + глава 600 (линейный парсер .doc→PDF)
python3 tools/extract_qsk60_catalog.py      # + глава 700 (координатный парсер PDF-опций)
python3 tools/extract_manual.py             # руководство -> manual.html + manual_media/
python3 tools/extract_service.py            # ремонт по разделам -> service/ + service.js
python3 tools/extract_prices.py             # цены (последним — чтобы охватить все главы)
python3 tools/set_catalog_password.py "<пароль>" 2026-07-31 31   # срок действия + пароль

# проверка полноты по основной книге — «0 потерянных номеров»
# (передайте распакованный PDF; extract_pdf_catalog.py распаковывает его во временную папку)
python3 tools/verify_completeness.py catalog/data/parts.js "путь/к/NTE240 Part Book-Polyus.pdf"
```

Извлекатели инвертора и QSK60 печатают собственную строку полноты
(`printed vs captured`) — она обязана быть `missing: 0`.

Проверка `verify_completeness.py` сверяет **каждый** номер детали, физически
напечатанный в колонках источника, с извлечёнными данными по всему документу
(не только по страницам с заголовком таблицы) — результат обязан быть
`0 потерянных номеров`.

## Данные

`catalog/data/parts.js` — `window.CATALOG`:

```
{ chapters:[{code,zh,en}],
  sections:[{ code, chapter, zh, en,
    figures:[{ images:[path…], parts:[{nc,ref,qty,pn,zh,en,lvl}] }] }],
  stats:{sections,parts} }
```

`catalog/data/prices.js` — `window.PRICES = { "<артикул>": {p:цена, g:группа, x:взаимозам, n:RU-наименование} }`.

## Скилл для других каталогов

`skill/parts-catalog/` — переносимый набор (SKILL.md + `references/` + `scripts/`),
описывающий весь конвейер и все разобранные подводные камни, чтобы собрать такой
же интерактивный каталог для **других** книг/машин (другой двигатель, другая
модель самосвала и т.п.). Внутри — отдельные памятки по каждому типу источника
(координатный PDF, линейный .doc→PDF, русские PDF-опции Cummins, прайс-лист,
руководство) и по устройству веб-приложения.
