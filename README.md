# NTE240 — интерактивный каталог запасных частей (публикация)

Готовый **самодостаточный** веб-каталог запчастей самосвала **NHL NTE240** с
подробным каталогом двигателя **Cummins QSK60**. Ветка `main` содержит только
сам сайт (корень репозитория = корень сайта) и предназначена для публикации на
**Vercel** — сборка не требуется, всё работает как статические файлы.

## Публикация на Vercel

- Framework preset: **Other** (статический сайт, без сборки).
- Build Command: пусто. Output/Root Directory: **корень репозитория** (`/`).
- `index.html` уже лежит в корне — Vercel отдаёт его как главную страницу.
- `vercel.json` задаёт долгий кэш для картинок/стилей/скриптов.

Открыть локально: `index.html` двойным щелчком (работает из `file://`).

## Что внутри

- `index.html`, `app.js`, `styles.css`, `gate.js` — основной каталог NTE240.
- `data/` — данные каталога (`parts.js`, `prices.js`, `service.js`).
- `drawings/`, `service_media/`, `manual_media/` — иллюстрации.
- `manual.html`, `service.html`, `service/` — руководство и инструкции по ремонту.
- **`engine/`** — подробный каталог двигателя **Cummins QSK60** (ESN 33239746,
  CPL 3451): 92 системы, 1041 деталь, чертежи узлов, фотографии и характеристики
  деталей, цены (CNY) из прайса NTE240. Открывается кнопкой «🛠 Каталог двигателя
  QSK60 (Cummins)» в шапке и ссылкой в разделах главы 700. У 8 узлов, для которых
  Cummins не публикует чертёж, чертёж дополнен из PDF-каталога (с пометкой).
  Глава 700 самого каталога NTE240 — «Двигатель Cummins QSK60 (из PDF)».

## Пароль и срок действия

Основной каталог и каталог двигателя (`engine/`) закрыты одним паролем и сроком
действия (`gate.js` в корне и в `engine/`). На Vercel (один домен) пароль
вводится один раз для обоих. Текущий пароль — `razum`; сменить его можно
скриптом `tools/set_catalog_password.py` из ветки `rawdata` (он обновляет оба
`gate.js`).

## Исходники и инструменты сборки

В ветке `main` их нет намеренно (чтобы деплой оставался лёгким). Полный
репозиторий со всеми исходниками (`sources/` — PDF/XLSX/ZIP), скриптами
извлечения (`tools/`) и переносимым скиллом (`skill/`) — в ветке **`rawdata`**.
